# indexprot

Index encode/decode helpers for prot payloads in pipelines.

**Site:** https://theworker02.github.io/indexprot/

## Install / run

```bash
git clone https://github.com/theworker02/indexprot.git
cd indexprot
node src/cli.js
node --test
```
